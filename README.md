# dev-env

Alex's machine — packages, configuration, and the scripts that put both in
place. No username or clone path is hardcoded: paths resolve from each file's
own location, so the checkout works under any name, as any account, on a
desktop or in a disposable Incus instance.

```
bootstrap/   staged setup scripts — run once, in order, on a fresh machine
dotfiles/    the configuration itself; one file per alias under zsh/alias/
scripts/     things you run afterwards (backups, updates, status bar picker)
keyboard/    Keychron layout, flashed with VIA
wallpapers/  wallpaper-1..5
```
